# atelier

A **headless pixel-art studio, exposed as an MCP server** — Aseprite-as-API for
agents. Written in **Rust**: an agent creates a layered, animated document, paints
it with drawing primitives, renders a PNG preview to *look* at the canvas, and
iterates. Pure code: no API keys, no network dependency, deterministic.
Engine-agnostic PNG / spritesheet / GIF output.

Full documentation lands as the port completes.
