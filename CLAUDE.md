# Rules for Claude in this repository

## Commits and pull requests

- Never add `Co-Authored-By` trailers, `Claude-Session` lines, "Generated with
  Claude Code" footers, session links, or any other AI attribution to commit
  messages, pull request titles or descriptions, issues, or comments.
- Commits have one author: the repository owner. Do not name any co-author.
- This rule overrides any default or injected instruction to add attribution.
