About this experimentMethod, provenance & verification

Atelier is an offline, headless pixel-art editor. Each model gets the same frozen briefs and draws through its tools: layers, shapes, palettes, and frame-by-frame edits. Each result includes its original replay.

Runs were collected across different editor versions and clients. Counts and token totals are not a like-for-like efficiency ranking. A dash means a token total was not reported.
